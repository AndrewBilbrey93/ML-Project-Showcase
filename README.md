# Machine Learning Projects

This repository contains a collection of machine learning projects demonstrating various techniques and methodologies.


## Movie Recommender (2020)

A project developed for a Big Data class, leveraging Apache Spark to build a movie recommendation system. The system utilizes the Alternating Least Squares (ALS) algorithm to suggest movies based on user preferences and behavior. 

### Key Features:

Collaborative filtering for personalized recommendations
Efficient handling of large datasets using Spark
Evaluation of recommendation accuracy through metrics such as RMSE


## Sound Recognition (2020)

This capstone project for my Master’s degree involved extracting audio features from both structured and unstructured audio clips. The project aimed to predict the likelihood of successful audio clip recognition and compared these predictions to actual accuracy ratings.

### Key Components:

Audio feature extraction techniques (e.g., MFCC, chroma features)
Model evaluation using precision, recall, and accuracy metrics
Insights into the effectiveness of different recognition algorithms

### Technologies Used:

Python, TensorFlow, and associated libraries for machine learning
Apache Spark for data processing in the Movie Recommender
Sound analysis libraries for audio feature extraction
